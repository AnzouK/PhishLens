Datenschutzerklärung von PhishLens

Zuletzt aktualisiert: 15. Oktober 2026.

PhishLens ist eine Chrome-Erweiterung, die E-Mails auf Phishing prüft. Diese Seite erklärt, welche Daten sie verarbeitet, wohin diese gehen und was gespeichert wird. Sie gilt für die Erweiterung und den gehosteten Server PhishLens Cloud unter anzouk.duckdns.org.

Kurz gesagt

  • PhishLens liest eine E-Mail nur, wenn Sie darum bitten (die Schaltflächen Prüfen), oder automatisch, wenn Sie in den Einstellungen Neue E-Mails automatisch prüfen einschalten (standardmäßig aus).
  • Die E-Mail wird an den in den Einstellungen gewählten Server gesendet: Ihren eigenen Computer (lokal mit Docker oder Python), Ihren eigenen Server oder PhishLens Cloud. Die Erweiterung sendet nichts anderswohin, außer den Meldungen, die Sie senden möchten (siehe unten).
  • Der Server prüft die E-Mail und gibt ein Urteil zurück. Er speichert weder E-Mail-Inhalte noch Absender oder Betreffzeilen.
  • Ihr Prüfverlauf bleibt in Ihrem Browser. Er wird nie hochgeladen.
  • Es gibt keine Konten, keine Analyse-Tools, keine Werbung und keinen Verkauf von Daten.
  • Sie können ein falsches Urteil melden oder die Statistik Ihrer Bewertungen teilen. Gesendet wird nur, was Sie sehen und bestätigen: der Text der E-Mail ohne Namen, Adressen, Nummern und Link-Pfade, oder eine Statistik ohne jeden E-Mail-Inhalt.

Was die Erweiterung liest

Bei einer Prüfung liest die Erweiterung aus der geöffneten Gmail- oder Outlook-Seite:

  • den Text der Nachricht, ihren Betreff und die Adresse des Absenders;
  • die Ziele der Links in der Nachricht;
  • die Authentifizierungshinweise, die Gmail anzeigt (gesendet von, signiert von);
  • bei eingeschaltetem Vollständige Header lesen (Standard) die Originalnachricht, wie sie die Gmail-Seite „Original anzeigen“ liefert: alle Header und die Textteile, ohne die angehängten Dateien;
  • bei der Prüfung eines Anhangs die angehängte Datei.

Das Fenster der Erweiterung liest außerdem Dateien, die Sie dort ablegen, und Text, den Sie einfügen.

Wohin die Daten gehen

Alle Prüfanfragen gehen an einen einzigen Server, den Sie in den Einstellungen der Erweiterung wählen:

Auswahl Wohin Ihre E-Mail geht
Lokaler Server Ihr eigener Computer (127.0.0.1:8000). Nichts verlässt ihn, außer den unten genannten Abfragen von Bedrohungsdaten.
Eigene URL Der Server, den Sie eingegeben haben. Es gilt die Richtlinie seines Betreibers.
PhishLens Cloud Der gehostete Server des PhishLens-Autors bei Oracle Cloud. Nichts wird gespeichert (siehe unten).

Der Server prüft die in einer E-Mail gefundenen Links bei Diensten für Bedrohungsdaten. Dazu sendet er nur die Linkadressen (nie den E-Mail-Text, den Absender oder den Betreff):

  • Google Safe Browsing (vollständige URLs, wenn ein API-Schlüssel eingerichtet ist);
  • URLhaus von abuse.ch (vollständige URLs);
  • Spamhaus DBL (Domainnamen, über DNS);
  • PhishTank (Abgleich mit einer auf den Server heruntergeladenen Liste; keine Anfrage pro E-Mail).

Meldungen, die Sie senden möchten

Unter jedem Urteil zeigt PhishLens die erkannte Sprache und einen Link Falsches Urteil? Melden; die Ansicht Statistiken bietet denselben Link für Prüfungen, die Sie als Falsch markiert haben, und eine Schaltfläche Meine Statistik teilen. Nichts wird gesendet, bevor Sie auf Senden klicken, nachdem Sie gelesen haben, was gesendet wird.

Meldung Was gesendet wird Was nie gesendet wird
Falsches Urteil Betreff, Text und Link-Domains dieser E-Mail nach der Anonymisierung (Namen nach einer Anrede oder einem Titel, Ihr eigener Name und Ihre Adresse, wie sie auf der Mail-Seite stehen, E-Mail-Adressen, Telefonnummern, lange Nummern wie Konten, Karten und Codes, IBAN, @Handles und Benutzernamen, Pfad und Parameter jedes Links), der Text so, wie Sie ihn bearbeitet haben, das Urteil, die Werte, der Bewertungsweg, die erkannte Sprache und Ihre Antwort, die Version der Erweiterung und die Sprache der Oberfläche Die Adresse des Absenders, die Original-E-Mail, ihre Header und Anhänge
Statistik Für jede Prüfung in Ihrem Verlauf: der Tag, wo geprüft wurde (Gmail, Outlook, Fenster der Erweiterung), das Urteil, die Werte, ob der Absender vertrauenswürdig war, Ihre Bewertung Richtig / Falsch, die erkannte Sprache und Ihre Antwort Betreffzeilen, Absender, Texte, Links

Meldungen gehen an PhishLens Cloud, egal welchen Server Sie für die Prüfungen nutzen. Der Server anonymisiert den Text ein zweites Mal mit denselben Regeln, speichert die Meldung ohne Ihre IP-Adresse oder andere Anfragedaten (das unten beschriebene Protokoll des Webservers erfasst die Anfrage dennoch 30 Tage lang) und gibt eine Referenz zurück. Meldungen dienen nur dazu, PhishLens zu messen und zu verbessern (zum Beispiel, um das Textmodell mit legitimen E-Mails zu trainieren, die es falsch beurteilt hat); sie werden nie veröffentlicht oder weitergegeben. Sie werden höchstens zwei Jahre aufbewahrt. Um eine Meldung löschen zu lassen, eröffnen Sie ein Issue unter https://github.com/AnzouK/PhishLens/issues mit ihrer Referenz (die Referenz allein verrät nichts über die Meldung).

Damit Sie auch aus der Ansicht Statistiken melden können, bleibt der anonymisierte Text Ihrer letzten Gmail- und Outlook-Prüfungen 7 Tage lang in Ihrem Browser (höchstens 50 E-Mails). Er verlässt den Browser nie, außer Sie melden diese Prüfung.

PhishLens Cloud zählt außerdem Urteile pro Bewertungsweg für die Überwachung (Prometheus-Zähler). Das sind nur Zahlen, ohne E-Mail-Daten.

Diese Website

anzouk.duckdns.org setzt keine Cookies und verwendet keine Tracking-Skripte, daher gibt es nichts zuzustimmen. Besucherzahlen stammen aus den Protokollen des eigenen Webservers (Seite, Zeit, verweisende Seite, Browsertyp, IP-Adresse) und werden mit einem selbst betriebenen Werkzeug ausgewertet; sie werden 30 Tage aufbewahrt und nie weitergegeben. Die Seite fragt die öffentliche API von GitHub nach der neuesten Versionsnummer, was GitHub als normale Anfrage Ihres Browsers sieht.

Ihre Möglichkeiten

  • Schalten Sie Vollständige Header lesen oder Neue E-Mails automatisch prüfen jederzeit in den Einstellungen aus.
  • Verwenden Sie den lokalen Server, damit E-Mails Ihren Computer nie verlassen.
  • Löschen Sie den Verlauf in der Ansicht Statistiken, oder entfernen Sie die Erweiterung, um alles zu löschen, was sie gespeichert hat.
  • Wenn Sie nie eine Meldung senden, verlässt nichts Ihren Browser außer den Prüfungen selbst, an den von Ihnen gewählten Server.

Kinder

PhishLens richtet sich nicht an Kinder und erhebt nicht wissentlich Daten über sie.
