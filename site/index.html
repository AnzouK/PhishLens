What it does

  • Fine-tuned DistilBERT text classifier (F1 ≈ 0.97)
  • Trained Random Forest agents for URLs (23 feats) and headers (37 feats)
  • SPF / DKIM / DMARC parsing + organizational-domain alignment
  • URL reputation cascade: cache → Google Safe Browsing → PhishTank → URLhaus → Spamhaus DBL
  • LIME token-level explanation for every verdict

How to try it

  1. Clone the GitHub repo
  2. Open chrome://extensions → Developer mode
  3. Click Load unpacked → pick extension/
  4. Open Gmail — a 🛡 Scan with PhishLens pill appears next to the subject

Tech stack

  • FastAPI · PyTorch · Transformers
  • scikit-learn · LIME · httpx
  • Chrome MV3 · vanilla JS · no build step
  • Docker · Caddy · Let's Encrypt
  • Deployed on Oracle ARM Ampere A1
