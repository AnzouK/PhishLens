How it works

Three models, real evidence, one clear answer

A language model alone flags real bank emails, because they sound like phishing. PhishLens checks the facts before it decides.

Read

The extension takes the open email in Gmail: text, links, sender and Gmail's own authentication results.

Score

DistilBERT scores the wording, two Random Forests score the links and the headers.

Verify

SPF, DKIM and DMARC prove who sent it. Links are checked against Safe Browsing, PhishTank, URLhaus and Spamhaus.

Explain

You get a verdict, a score per agent and the words that pushed the decision, right above the email.

Features

Built for how phishing actually arrives

Explainable verdicts

LIME highlights the words that pushed the text model toward phishing or safe, so you can judge for yourself.

Sender authentication

DKIM alignment with the From: domain proves the sender. A spoofed PayPal signed by another domain stays under suspicion.

Threat intelligence

Every link goes through Google Safe Browsing, PhishTank, URLhaus and Spamhaus, with a local cache.

Attachments

PDFs (OCR for scanned ones), images, QR codes, HTML pages, and Word, Excel or PowerPoint files with macros or remote templates.

Private by design

No account, no email stored on the server. Run your own backend with Docker and nothing leaves your machine.

Open and tested

MIT licensed, with a threat model, CI, CodeQL and more than a hundred automated tests.

Install

Two minutes to set up

The Chrome Web Store listing is on the way. Until then, load the extension from the repository.

1. The extension

  1. Download or clone the repository.
  2. Open chrome://extensions and turn on Developer mode.
  3. Click Load unpacked and select the extension/ folder.
  4. Open an email in Gmail and click Scan with PhishLens.

2. A backend

  1. Cloud demo: nothing to do, pick it in the extension settings.
  2. Your own, private: run it with Docker, then pick "Local".
huggingface-cli download AnzouKiona/phishlens-distilbert \
  --local-dir backend/model
cd backend && docker compose up --build
